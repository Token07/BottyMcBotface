Botty McBotface Privacy Policy

Last updated: 2026-10-17

Botty McBotface ("the bot") is a Discord bot run by the staff of the Riot Games Third Party Developer Community Discord server ("the server", "we", "us"). The bot runs in that server and in a public development server (Botty Development), which is used for testing and to receive the bot's logs. The log channels in the development server are restricted to server staff. It cannot be added to other servers. This policy applies to both servers.

The server has been run by community volunteers since August 2021. The bot is operated by the server's community staff, not by Riot Games, and Riot Games is not responsible for the bot or for how it handles your data. This policy explains what data the bot accesses, what it keeps, and why.

What the bot can see

While you are a member of the server, Discord gives the bot access to:

  • Messages you post in channels the bot can read, including their text, attachments and links, and when they are edited or deleted.
  • Member information: your user ID, username, display name and nickname, roles, and when you join or leave the server or are banned.
  • Reactions you add to messages.
  • Commands you use, including slash commands.

The bot does not access your presence or activity status, your voice activity, or your direct messages with other users.

How the bot uses this data

Moderation and security. The bot scans messages to detect and remove spam, scams, phishing links, and similar abuse. This includes:

  • Rule-based filters, such as blocked links, invite spam, and the same message posted across multiple channels.
  • A self-hosted spam classifier that scores each message. The classifier processes message text in memory only and does not store it.

When a message is removed, the bot posts a notice, and the removed message is logged to a staff-only channel. Staff and trusted roles are exempt from spam filtering.

Leaked API key protection. If you post an API key in a public channel by mistake, the bot reports it to a staff-only channel so staff can warn you.

Moderation logging (trust and safety). Member joins, leaves, bans, name changes, and edited or deleted messages are logged to staff-only channels. This lets staff investigate spam waves, raids, impersonation, compromised accounts, and other abuse, and keep a record of moderation actions.

Features you use. The bot reads messages to react to greetings and 🤔 messages. When you use a command, the bot processes the options you give it, such as a name or date to look up, only to run that command.

API URLs you paste. If you paste a game API URL, the bot makes that request using the bot's own API key and posts the response in the channel. No information about you is sent with the request. If the URL you paste contains your own API key, that key is sent as part of the URL. It is also visible in the bot's reply and will be reported as a leaked key (see above), so don't include keys in URLs you paste.

Third-party services

To provide its features, the bot makes requests to public services, including Riot Games, CommunityDragon, and GitHub. Most of this data is fetched on a schedule and cached. Requests made because of a command contain only what the command needs (for example, a programming language name) and no information about you, except for API URLs you paste yourself, described above.

Who can access your data

  • Server staff (Gurus and Admins) can see the bot's staff-only log channels, including removed messages, detected API keys, and moderation logs. Staff include volunteers from the developer community and some Riot Games employees.
  • The bot's maintainer, who is the only person with access to the bot's host, can access the bot's stored data files, spam classifier statistics, and system logs.
  • Discord stores everything the bot posts to Discord channels, under Discord's own privacy policy.

No one else has access to the data the bot stores.

What we don't do

  • We do not sell your data, and we do not share it with anyone outside the people listed under "Who can access your data".
  • Botty McBotface does not use your data, including message content, to train machine learning or AI models. Its spam classifier is built from a hand-curated dataset, not from data the bot collects.
  • We do not use your data for advertising or profiling.

Security

All data the bot stores, including data files, spam classifier statistics, and system logs, is kept on a server with full-disk encryption.

Your choices

  • You can opt out of the bot's emoji reactions with /toggle_react.
  • You can have the bot react to your 🤔 messages with the default thinking emoji instead of custom ones with /toggle_thinking.
  • Running either command again reverses it and deletes your stored preference.
  • Message scanning for spam, scams, and leaked keys applies to all members and cannot be opted out of, because it protects the whole server.

Deletion requests

Most of the data the bot keeps is held for trust and safety purposes, such as spam records and moderation logs. These records are generally retained for those purposes and may not be deleted on request. Your reaction preferences can be removed at any time by running /toggle_react or /toggle_thinking again, or on request.

To ask about your data or request deletion, contact any Guru or Admin in the server.

Changes to this policy

We may update this policy when the bot changes. The "Last updated" date at the top shows the latest revision.

Contact

Questions about this policy can be sent to any Guru or Admin in the server.
